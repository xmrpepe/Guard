# RocksGuard 1.0.0 beta 1 — The Scottish Guardian

**Forged in Scotland. Built for Privacy.**

The first public build of RocksGuard: an on-device VPN that blocks adverts, trackers and malicious domains for every app, encrypts DNS, and adds a per-app firewall. There's no account, no adverts and no analytics.

> ⚠️ **Beta: not yet tested on real devices.** The security engine is covered by automated tests and the interface renders correctly, but this build has not been run on a phone or emulator. Please report anything that misbehaves, along with your Android version and phone model.

## Highlights
- **The Fortress:** one-tap protection with an animated Highland shield, live counters for adverts, trackers and threats, and a dashboard you can arrange.
- **The Lookout:** a live, searchable DNS log that explains every block in plain English. Allow or block a domain with one tap.
- **The Ramparts:** a per-app firewall for Wi‑Fi and mobile data. Watch Gate blocks by DNS; Sealed Gate cuts restricted apps off completely.
- **The Watchtower:** DNS over HTTPS or TLS with Quad9, Cloudflare, Mullvad, DNS4EU, AdGuard or Google, plus automatic failover and measured latency.
- **The Shield and the Armoury:** category switches, unmasking of disguised (CNAME-cloaked) trackers, your own rules, and 13 downloadable filter lists plus custom lists.
- **The Keep:** a fortress inspection with real security checks, and a privacy report.
- **Seven themes**, each in light and dark, with schedules, custom accents, reduced motion and a lite-effects mode for entry-level phones.

## Install
1. Download `RocksGuard-v1.0.0-beta.1.apk` below. You can check it against the `.sha256` file.
2. Allow installing from your browser or file manager when Android asks.
3. Open RocksGuard and tap the shield. Android will ask once to allow the VPN.

Requires Android 8.0 or later. Identifying which app made each lookup, and Watch Gate app rules, need Android 10 or later.

## Known limitations
- Watch Gate can't stop apps that connect to hard-coded IP addresses; use the Sealed Gate for those.
- While the Sealed Gate is active, ad filtering pauses for other apps, because Android can't route apps differently inside one VPN.
- If Android's **Private DNS** is set to a specific provider, it bypasses RocksGuard. The app detects this and tells you how to fix it.
